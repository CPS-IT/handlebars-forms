================
Handlebars Forms
================

:Extension key:
    :t3ext:`handlebars_forms <handlebars_forms>`

:Package name:
    :composer:`cpsit/typo3-handlebars-forms`

:Version:
    |release|

:Language:
    en

    coding. powerful. systems. CPS GmbH

    (Creative Commons) license.

----

An extension for TYPO3 CMS that provides form rendering with Handlebars,
based on the :t3ext:`handlebars` extension. It is designed to provide rendering
options for all default form elements shipped by EXT:form, while rendering for
custom form elements can be easily configured using dedicated interface implementations.
