================
Developer corner
================

This section covers extension points for developers who need to go beyond what the
built-in :typoscript:`HBS_*` content objects and view model builders provide. It starts
with a reference of all view models built for the default form elements, followed by
extension points ordered from mapping custom form elements to view models to resolving
custom values with dedicated content objects.
